# Roadmap

## 0. Establish the study

- [x] Choose the public premise and repository name.
- [x] Define the first Protect PP study and research controls.
- [ ] Add the validated study specification and repository checks.

## 1. Verify mechanics and reproduce a baseline

- [ ] Connect a local Showdown process through a pinned Python adapter.
- [ ] Verify 16 and 8 maximum Protect PP with deterministic fixtures.
- [ ] Verify Rage Fist power before switching and after returning.
- [ ] Verify equivalent legal Speed builds and move order.
- [ ] Freeze the team pool, information rules, and known simulator mismatches.
- [ ] Reproduce a competent source agent and record its resource costs.

Exit when legal battles complete, targeted fixtures pass, and baseline results are reproducible. A random agent is useful for plumbing but is insufficient as the only strength baseline.

## 2. Produce the first Protect result

- [ ] Pilot evaluation size and set the compute budget.
- [ ] Freeze test teams, opponent policies, and seeds.
- [ ] Compare unchanged source, adapted, and target-native agents.
- [ ] Evaluate multiple training seeds and report confidence intervals.
- [ ] Produce one replay explanation with repeated-rollout evidence.

Exit with a reproducible result and a replay whose explanation matches the aggregate evidence. A null or negative result is publishable when the experiment can resolve a useful effect.

## 3. Measure habit recovery

- [ ] Add Rage Fist and Speed studies separately.
- [ ] Normalize candidate mistakes by eligible decision opportunities.
- [ ] Test selected interactions between rule changes.
- [ ] Compare original and adapted checkpoints without inferring unsupported internal beliefs.

## 4. Evaluate full Champions transfer

- [ ] Pin a dated regulation and validate the complete target ruleset.
- [ ] Measure transfer loss and recovery on held-out teams.
- [ ] Compare fixed and new opponent pools.
- [ ] Build legal OTS reference matchups and record their sources.

## 5. Build the public showcase

- [ ] Blunder Replay with PP, damage, Speed, and outcome evidence.
- [ ] Habit Recovery charts with uncertainty and opportunity counts.
- [ ] Matchup Desk with teams, replays, configuration, and provenance.
- [ ] Keyboard and mobile replay navigation.

See [the showcase brief](docs/showcase.md) when the measured result is ready.

## 6. Extend to Tera/Mega

- [ ] Compare both transfer directions and equal-budget native references.
- [ ] Document common species and unavoidable item/form differences.
- [ ] Separate mechanic changes from unrelated rule changes.
- [ ] Publish the limits of conclusions about human skill and metagame optimality.
